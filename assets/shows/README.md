# Show logos

One file per show, named by the show id in `data/shows.js`:

```
assets/shows/disruption.png   The Disruption Lab
assets/shows/eko.png          The EKO System
assets/shows/court.png        Court Ordered
assets/shows/sessions.png     Keystone Sessions
```

PNG or SVG with a transparent background, square works best (it is shown at 18, 40 and 112 px). A wide logo is fine too; it is cropped to fit. Until a file is here the site shows a monogram tile in the show's brand color, so a missing logo never breaks a page.

Brand color and the text color that sits on it are `color` and `ink` in `data/shows.js`.
